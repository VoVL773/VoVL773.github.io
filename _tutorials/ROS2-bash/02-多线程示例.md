Python 文件示例：

```python
import threading
import requests

class Download:
    def __init__(self):
        pass

    def download(self, url, callback_word_count):
        # threading.get_ident() 返回当前线程的编号，用于确认"确实开在新线程里"
        print(f"线程：{threading.get_ident()}开始下载：{url}")
        response = requests.get(url)
        response.encoding = 'utf-8'   # 手动指定编码，否则中文可能乱码
        # 下载完成后调用回调函数，把结果"交回"给调用方
        callback_word_count(url, response.text)

    def start_download(self, url, callback_word_count):
        # 创建线程：target 是线程要执行的函数，args 是传给它的参数元组
        thread = threading.Thread(target=self.download, args=(url, callback_word_count))
        thread.start()   # start() 才真正启动线程；调用后会立刻返回，不等待下载完成

def word_count(url, result):
    """普通函数用于回调"""
    print(f"{url}:{len(result)}->{result[:50]}")   # 只打印前 50 个字符，避免刷屏

def main():
    download = Download()
    # 三次调用几乎同时发起 → 三个线程并发下载，总耗时接近"最慢的那一个"，而不是三者相加
    download.start_download("链接1", word_count)
    download.start_download("链接2", word_count)
    download.start_download("链接3", word_count)

if __name__ == "__main__":
    main()
```


> 💡 **知识点：什么是回调（callback）**
>
> `word_count` 就是个回调函数——你把它**当作参数传进去**，由 `download` 在合适的时机替你调用。
>
> 这样写的好处是**解耦**：`Download` 类只管下载，不关心拿到结果后要干什么（打印、存文件、发到 ROS 话题都行）。这个模式在 ROS 2 里到处都是——订阅、定时器、服务响应，本质上都是"注册一个回调，等事件发生时被调用"。

> 💡 **知识点：`args=(url, callback_word_count)` 里的逗号不能少**
>
> `args` 必须是**元组**。单个参数时写成 `args=(url)` 会被当成普通括号（不是元组），必须写成 `args=(url,)`。多参数时 `(a, b)` 本身就是元组，没问题。

> ⚠️ **注意：Python 有 GIL，多线程不等于真并行**
>
> 由于全局解释器锁（GIL），多个 Python 线程**同一时刻只有一个在执行字节码**。那为什么这个例子还有用？
>
> 因为 `requests.get()` 是 **I/O 操作**：等待网络返回时线程会**释放 GIL**，此时其它线程可以继续跑。所以**I/O 密集**任务（下载、读文件、等接口）用多线程有效；**CPU 密集**任务（大量计算）用多进程 `multiprocessing` 才有意义。
>
> 这一点直接决定了后面 ROS 2 + Qt 的写法：`rclpy.spin()` 放子线程、Qt 界面留主线程，正是因为 spin 大部分时间在等消息（I/O），不会霸占 CPU。

```python
entry_points={

            'test_node = Ros2_learn.download_test:main',
        ],
    },
```

> ⚠️ **注意**：这里的包名 `Ros2_learn` 和第一节的 `demo_python_pkg` 不一样，是两份独立示例。实际操作时**要和你自己创建的包名一致**，否则 `ros2 run` 会报找不到包。全文出现过好几个不同的包名，跟着做的时候注意替换。
