关于

这里是 算法题解与见解 站点，用来记录 LeetCode 等平台的刷题记录、 题解思路以及对算法思想的总结与反思。

每道题都提供 C++ 与 Python 两种语言的题解， 方便对照学习。点击首页题目卡片即可进入详情页查看完整代码。

站点结构

  • 首页：LeetCode 题解卡片列表
  • 见解：刷题过程中的思考与总结
  • 博客：返回主博客（生活与技术随笔）
  • 关于：本站介绍

题解规范

  • 每题附题目描述、思路说明与完整代码
  • 代码默认提供 C++ 与 Python 两种实现，可在详情页切换
  • 题目按 LeetCode 编号排序，难度标注：简单 / 中等 / 困难
