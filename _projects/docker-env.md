## 项目简介

搭建基于 Docker 容器的开发环境，实现环境隔离、GPU 加速和可视化界面，提升跨机器部署与协作效率。

## 主要功能

- 多套开发环境的容器化封装
- NVIDIA GPU 加速支持
- GUI 应用可视化转发
- 一键启动与环境复刻

## 技术栈

Docker、Docker Compose、NVIDIA Container Toolkit、ROS 2
